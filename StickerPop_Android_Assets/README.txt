StickerPop Android Assets
=========================

App icon:
- stickerpop_icon_1024.png — master
- stickerpop_icon_512.png ... stickerpop_icon_36.png — launcher sizes
- The launcher icon contains ONLY the mascot icon; there is no StickerPop wordmark.

Splash:
- stickerpop_splash_1080x2400.png — primary splash artwork
- Additional resolutions: 1080x2280, 1080x1920, 720x1280

Brand colors:
- Yellow: #FFD600
- Navy: #0B1533
- Cyan: #00B8E6
- Green: #34C759
- Pink: #FF4D8D
- Orange: #FF9F1C
- Background: #F5F7FA

Note:
For Android 12+, the OS splash-screen system uses a background color and an app icon rather than an arbitrary full-screen bitmap. The provided full-screen PNG is useful for pre-Android-12/custom splash implementations; use #FFD600 and the icon for the Android 12 SplashScreen API.
